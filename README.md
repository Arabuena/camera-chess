
# Camera Chess – MVP


MVP para detecção automática de tabuleiro de xadrez físico usando visão computacional, React, OpenCV.js, chess.js, chessboardjsx e Stockfish WASM.

## Objetivo

Capturar vídeo da câmera, detectar a grade do tabuleiro, mapear as 64 casas, identificar mudanças entre frames, converter em lances e atualizar o tabuleiro virtual.

## Tecnologias
- React + Vite
- chess.js
- chessboardjsx
- OpenCV.js
- Stockfish WASM

## MVP – Passos
1. Detectar o tabuleiro (OpenCV.js)
2. Mapear as 64 casas
3. Detectar mudança entre frames
4. Converter em lance (chess.js)
5. Atualizar tabuleiro virtual (chessboardjsx)

## Deploy
PWA pronto para deploy no Vercel ou Netlify.
